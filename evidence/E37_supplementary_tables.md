## Results
- **S2.** Release: Perl = Python on all five sets (737, 786, 2,584, 69, 60 ORFs; 0 start
  differences, 0 implementation-only ORFs). v6.0.0 vs first port: implementation-only ORFs on
  Trinity (1/4) and StringTie (22/30); same stop, different start in 15, 67, 71, 0 and 4 ORFs.
- **S5.** 1,207 rows: 15 input types × 8 organisms × 13 run labels where run. Rows per label:
  pytd_v7 108, perl_td_v7 108, pytd_v7_homology 84, perl_td_v600 104, prodigal 108, gmst 105,
  codan 100, cpat 108, cpc2 105, rnasamba 65, borf 105, longest_orf 104, angel 3. Column
  `genetic_code_supported` = "no" marks the five methods without the ciliate code on *T. thermophila*.
- **S6.** Exact matches on stranded complete inputs. PWM choice vs first ATG: lower in six organisms,
  +1 in *P. falciparum* (4,824 vs 4,823), +69 in *C. reinhardtii* (12,661 vs 12,592). Median exact
  F1: first ATG 0.893, PWM choice 0.887, v6.0.0 0.779, scale-corrected PWM 0.728, release 0.912.
  Seeds 2–5 changed 53/30/61/29 starts (PASA, 792 ORFs) and 144/47/111/54 (StringTie, 3,037).
- **S8.** L* 519 nt at 25% G+C to 2,436 nt at 80%; at least 85,056 random ORFs per level. The
  v5–v6 column is the code table of v5.0.0 and v6.0.0 (`@GC_TO_MIN_LONG_ORF_LENGTH`, checked in
  `work/trees/TD_base` at tags v5.0.0 and 66d4712); it is the 2017 q0.999 column hand-rounded
  (30%: 510; 80%: 2,422).
- **S9.** UTRs added per organism: 5′ 0 (*C. reinhardtii*) to 1,142 (*A. thaliana*); 3′ 0 to 947
  (*P. falciparum*). Three *D. melanogaster* genes have neither an annotated nor an added 3′ UTR.
- **Discussion (CodAn).** On complete *P. falciparum* transcripts CodAn (invertebrate model) had
  stop-level sensitivity 0.552 and F1 0.710; TransDecoder 0.994 and 0.997 (S5 rows
  `P. falciparum / complete`). CodAn's four clade models (vertebrates, invertebrates, plants,
  fungi) are from E16/E27.

## Checks
- S5 release rows are the `all_scores.tsv` rows; notebook 02 shows they agree with the interim
  summary for `pytd_v7`.
- S6 rows used from the working-tree `summary.tsv` are identical to those at HEAD (checked
  2026-10-30 while another task had uncommitted edits to that file).
- S6 release median exact F1 (0.912) and v6.0.0 (0.779), scale-corrected PWM (0.728) match the
  Results text; seeds match the text (29–61, 47–144).
- S9 counts match the E07 table and `benchmark_v2/README.md`; annotated + added + none = kept genes
  for both ends in every organism.
- Both documents compile with tectonic without errors or undefined references.

## Caveats
- The methods text said that choosing among later ATGs "did not improve accuracy in seven of the
  eight organisms; in *P. falciparum* it gained one exact match". S6 shows the organism that did
  improve was *C. reinhardtii* (+69), with *P. falciparum* +1 counted as no improvement. The
  sentence was reworded to state both (methods_algorithm.tex).
- S6 mixes development code (first ATG, PWM choice: PyTD efc1450; scale-corrected PWM: PyTD
  27bfb5e) with releases; it documents the earlier procedures, not the release rule.
- S5 is a TSV, not XLSX: no XLSX writer is installed in the project environments. Genome Biology
  accepts tab-separated additional files.
